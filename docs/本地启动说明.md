# 本地启动说明

《三命无常》设计原型是静态站点，不需要打包。用任意本地静态服务器即可。

## 环境

- Node.js 18 或更新（用于 `npm start`）
- 现代浏览器：Chrome / Edge / Firefox 均可
- 不要双击 `index.html` 用 `file://` 打开

## 方式一：npm（推荐）

在 `GamePrototype` 目录：

```bash
npm start
```

终端出现 `Accepting connections at http://localhost:4173` 后，用浏览器打开：

http://127.0.0.1:4173/

等价命令：

```bash
npm run dev
```

首次会通过 `npx serve` 临时拉取静态服务器，不把 `node_modules` 提交进仓库。

## 方式二：Python

没有 Node 时，在 `GamePrototype` 目录：

```bash
python -m http.server 4173
```

然后打开 http://127.0.0.1:4173/

## 方式三：VS Code / Cursor Live Preview

用 Live Preview 或类似扩展把站点根目录指到 `GamePrototype`，预览 `index.html`。

## 确认成功

1. 首页能看到孙悟空立绘和「进入试玩」。
2. 点「进入试玩」后出现开机校验，随后进入大厅。
3. 底栏点「战斗 HUD」应进入 1280×720 战场。
4. 「手册」能显示《美术总监工作手册》，而不是载入失败。

若手册或大厅英雄卡空白，几乎一定是还在用 `file://`。请改用上面的 HTTP 方式。

## 常用地址

| 用途 | 地址 |
| --- | --- |
| 设计工作台 | http://127.0.0.1:4173/ |
| 玩家前端（大厅） | http://127.0.0.1:4173/prototype/play/index.html?qa=1&screen=lobby |
| 战斗 HUD | http://127.0.0.1:4173/prototype/play/index.html?qa=1&screen=battle |
| 手机横屏 | http://127.0.0.1:4173/prototype/play/index.html?platform=mobile&screen=lobby |
| 验收面板 | 玩家前端内 `Ctrl+Shift+Q`，或 URL 带 `qa=1` |

## GitHub Pages

推送到 `https://github.com/cryangle0/sanming` 的 `main` 根目录后，在仓库 Settings → Pages 选择：

- Source: Deploy from a branch
- Branch: `main` / `/ (root)`

几分钟后访问 https://cryangle0.github.io/sanming/

## 常见问题

**大厅没有英雄图**  
确认 `prototype/assets/entity/` 下有 `H001`–`H038`。这些文件由 `tools/extract-delivery-assets.py` 从独立交付 HTML 抽出。

**开机停在「内容数据不可达」**  
必须通过本地 HTTP 访问，以便读取 `prototype/data/content-source.json`。

**想单独给程序看玩家前端**  
把 `prototype/play/index.html` 的链接发出去即可，不必经过工作台。
